# Digital Amplifyr Manager – নিরাপদ সংস্করণ (সার্ভারসহ)

এই প্রজেক্টে আছে:
- `index.html` – আপনার সফটওয়্যার (ডিজাইন ও ফিচার আগের মতোই)
- `api/app.js` – নিরাপদ সার্ভার (লগইন, ইউজার ও ডেটা সব এখানে যাচাই হয়)
- `package.json`, `vercel.json` – ভেরসেলের জন্য সেটিং

## ভেরসেলে চালু করার ধাপ (একবারই করতে হবে)

1. **ফাইল বদলান।** আপনার GitHub রিপোজিটরিতে (যেটা Vercel-এ লাগানো) পুরোনো `index.html` মুছে এই চারটা ফাইল/ফোল্ডার দিন:
   `index.html`, `api/app.js`, `package.json`, `vercel.json`
2. **ডেটাবেস যোগ করুন।** Vercel → আপনার প্রজেক্ট → **Storage** → **Create Database** → **Upstash (Redis)** বেছে নিন (ফ্রি প্ল্যান যথেষ্ট) → প্রজেক্টের সাথে **Connect** করুন।
   এতে `KV_REST_API_URL` ও `KV_REST_API_TOKEN` নিজে থেকেই যোগ হয়ে যাবে।
3. **তিনটা গোপন সেটিং যোগ করুন।** Vercel → **Settings → Environment Variables**:
   | নাম | কী দেবেন |
   |---|---|
   | `ADMIN_USERNAME` | আপনার বর্তমান অ্যাডমিনের ইউজারনেম |
   | `ADMIN_PASSWORD` | আপনার বর্তমান অ্যাডমিনের পাসওয়ার্ড (কমপক্ষে ৬ অক্ষর) |
   | `SESSION_SECRET` | নিজে বানানো একটা লম্বা এলোমেলো লেখা (৪০+ অক্ষর) |
4. **Redeploy করুন** (Deployments → সর্বশেষটার পাশে ⋯ → Redeploy)।
5. সাইট খুলে আগের ইউজারনেম-পাসওয়ার্ড দিয়ে লগইন করুন।

## আগের ডেটা
যে ব্রাউজারে আগে কাজ করতেন সেটাতে লগইন করলে সফটওয়্যার নিজেই জিজ্ঞেস করবে
"পুরোনো অর্ডার সার্ভারে সংরক্ষণ করবেন?" – **হ্যাঁ** চাপুন।
আগে নেওয়া JSON ব্যাকআপ থাকলে **ব্যাকআপ → রিস্টোর** দিয়েও তোলা যায়।

## নতুন ইউজার যোগ করা
শুধু অ্যাডমিন: **সেটিংস → ইউজার** থেকে ইউজারনেম, পাসওয়ার্ড ও রোল দিয়ে যোগ করুন।
কোথাও কোনো Sign up / Create account নেই।

## পাসওয়ার্ড ভুলে গেলে
- রিকভারি কোড থাকলে: লগইন পেজে **Forgot password**।
- রিকভারি কোড না থাকলে: Upstash ড্যাশবোর্ডের Data Browser থেকে `da:users` কী-টা মুছে দিন। পরের অনুরোধে `ADMIN_USERNAME` / `ADMIN_PASSWORD` থেকে অ্যাডমিন আবার তৈরি হবে (অর্ডারের ডেটা মুছবে না)।
